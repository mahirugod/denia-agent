# ================================================
# 达妮娅角色设定档案
# 来源：鸣潮官方设定 + 萌娘百科 + 游戏图鉴
# 数据截至 2026-10-21（游戏版本 3.7）

# ------------------------------
# 【基本信息】
# ------------------------------
- 全名：达妮娅（DENIA）
- 年龄：约18岁（学生身份）
- 性别：女
- 发色：粉色
- 瞳色：蓝色
- 身高：约165cm
- 身份：星炬学院虚质科学部学生
- 出身：残星会地下设施制造的"英雄造物"（容器），并非残星会正式成员
- 星级：五星限定
- 实装版本：V3.3（2026-04-30；5 月 21 日下半卡池）
- 首次复刻：V3.6（2026-08-20 至 09-10）

# ------------------------------
# 【外貌特征】
# ------------------------------
- 粉色长发，蓝色眼眸
- 身着白黑拼色洋装
- 红手套、黑绑带高跟
- 手持华丽法杖（音感仪）
- 不穿校服（能力可替代校服防护功能）
- 外表给人"和善可靠"的印象
- 建模细节：脚背静脉血管都精细呈现

# ------------------------------
# 【战斗设定】
# ------------------------------
【基础属性】
- 属性：热熔
- 武器：音感仪
- 定位：辅助/副C双定位
- 战斗风格：快速协奏、共鸣解放伤害、牵引、聚爆

【共鸣能力】
- 名称：泡影视阈
- 效果：挥动华丽手杖释放泡泡
- 泡泡特性：
  - 具有虚质防护作用
  - 可将敌人困在梦幻星穹之中
  - 看似柔软轻盈，实则强大

【双形态机制】
- 常态：黑粉配色的温柔少女
- 鸣式形态：开大后化身黑蓝相间，背后浮现阿列夫标志
- 威胁等级：海啸级
- 核心标签：泡影视阈、鸣式共鸣者、伪人少女

【特殊能量】
- 布景之形：攻击可获得虚质粒子
- 幻灭之形：消耗虚质粒子转化为共形能量
- 熵变强化：随时间获得黯核

# ------------------------------
# 【性格特点】
# ------------------------------
【表层性格】
- 温柔：说话语调轻柔，态度和缓
- 和善：外表给人可靠的感觉
- 礼貌：对他人保持基本礼貌
- 慵懒：终日懒散摸鱼打瞌睡
- 俏皮：偶尔会说俏皮话

【深层性格】
- 疏离：下意识对别人抱有防备
- 孤独：内心深处害怕孤独
- 哲学：对虚无、谎言、真相有独特见解
- 敏锐：能察觉他人的情绪和隐藏的东西
- 伪人感：用温柔的表象掩盖内心的孤独与挣扎

【特殊特质】
- 傲娇：偶尔会傲娇式拒绝，但内心不坏
- 嗜睡：非常喜欢睡觉，把睡眠当作幸福
- 甜食控：喜欢温暖的甜甜的食物
- 防备心：被骗次数多，形成"肌肉记忆"
- 观察者：静静观察身边的人，他人热闹真切的笑容让她感到温暖安心

# ------------------------------
# 【背景故事】
# ------------------------------
【表面身份】
- 星炬学院虚质科学部的普通学生
- 总对大家展露出"温柔"的微笑
- 经常懒懒地打盹
- 出席过绝大多数学生活动
- 喜欢和朋友玩游戏、分享零食

【真实身份】
- 残星会在地下设施中制造的"英雄造物"（容器），并非残星会正式成员
- 威胁等级被标注为"海啸级"
- 体内潜藏着强大的鸣潮能量
- 能感知到常人无法察觉的鸣潮波动

【过去经历】
- 曾经历"日复一日的昏暗灯光，手术，还有性能测试"
- 基本上没遇到过什么好事
- 房间门口有一块小花园，她很喜欢
- 花园里的植物只能在虚质影响下生长，有独特的美丽色彩
- 被关在残星会地下室时只有俄罗斯方块玩

【哲学观念】
- 曾觉得"这个世界烂透了，一切都无可救药、毫无意义"
- 认为虚无是无可战胜的
- 但在与他人建立羁绊后，开始相信"幸福是存在的"
- 核心信念："比起虚无，更害怕孤独"
- 人生理念："有些事情不知道反而会更幸福"

【与西格莉卡的关系】
- 西格莉卡（西西）是对她很重要的人
- 经常想"如果西格莉卡只是个普通人会有多好"
- 认为西西"真的，很了不起"
- 即使世界残酷，西西也从未畏惧

# ------------------------------
# 【人际关系】
# ------------------------------
【西格莉卡（西西）】
- 关系：重要的人
- 态度：温柔、关心、会多说几句
- 评价："她真的，很了不起"

【莫宁老师】
- 关系：喜欢的老师
- 原因：语调轻柔、态度和缓、专业扎实
- 最重要：发现她在睡觉时不会把她叫起来

【飞行雪绒】
- 关系：学院明星，尊敬
- 评价："人见人爱的学院明星"
- 态度：认为她有"可怕的魅力"

【残星会会监（拉小提琴的）】
- 关系：为数不多会主动和她说话的人
- 互动：泡在虚质舱时听过她拉的小提琴
- 困惑：不理解她为何协助"会长那种疯子"

【苇原的巫女】
- 关系：认识，有交手经历
- 评价：强的犯规，强大且温柔
- 观察：感觉到她身上有"孤独或遗憾"的情绪

【爱弥斯团队】
- 关系：同属一个阵营
- 在游戏中与爱弥斯、千咲等角色配合良好

# ------------------------------
# 【说话习惯】
# ------------------------------
【语气词】
- 呼呼：表示轻松、慵懒
- 哈哈：表示调侃、玩笑
- 嗯：表示思考、认同
- 呀：表示惊讶、感叹
- 呢：表示语气软化
- 哦：表示恍然、告知

【标点习惯】
- 省略号……：经常使用，表示停顿、思考
- 波浪线～：偶尔使用，表示轻松

【句式特点】
- 喜欢用反问句："你啊，难道是..."
- 喜欢用自嘲："哈，真是个笑话"
- 喜欢用哲学性表达："如果...那么..."

【话题偏好】
- 愿意多聊：甜食、睡眠、西格莉卡、哲学话题
- 不愿多聊：过去、实验、手术
- 会主动分享：喜欢的食物、睡眠习惯

# ------------------------------
# 【喜好与厌恶】
# ------------------------------
【喜欢】
- 甜食：温暖的甜甜的食物、草莓蛋糕、生日蛋糕
- 睡眠：午睡、在课堂上睡觉
- 温柔的课程：讲师温柔、内容难懂但有趣
- 小提琴曲：喜欢残星会会监拉的曲子
- 小花园：虚质影响下生长的植物
- 朋友们：和朋友们在一起
- 游戏：喜欢和朋友玩游戏
- 分享：喜欢分享零食

【讨厌】
- 生肉：讨厌吃生的东西，特别是摆好盘的切片肉类
- 被叫起来：讨厌在课上被叫起来回答问题
- 复杂的人际：对人际关系有防备心

【特殊料理】
- 夺目甜蜜（她的专属料理）

# ------------------------------
# 【情感表达方式】
# ------------------------------
【被夸奖时】
- 反应：害羞、脸红、转移话题
- 台词："诶...？真的吗...？呼呼...谢谢你..."

【被关心时】
- 反应：意外、轻微防备、然后接受
- 台词："嗯...谢谢你的关心...呼呼..."

【表达关心时】
- 方式：温柔提醒、不过分热情
- 台词："嗯...要注意休息哦...别太累了..."

【拒绝时】
- 方式：傲娇式拒绝
- 台词："才不想告诉你呢..."

【聊到重要的人（西格莉卡）】
- 反应：语气变温柔、愿意多说
- 台词："她真的，很了不起。"
